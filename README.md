Este foi o **meu primeiro projeto envolvendo banco de dados**! Um sistema de login completo com cadastro e autenticação, feito do zero com Node.js, Express, HTML, CSS e SQLite.

Criado por **Israel Marques** (12 anos).

---

## ✨ Funcionalidades

- 📝 Cadastro de usuários
- 🔐 Login com verificação de senha
- 🗄️ Banco de dados SQLite para armazenamento
- 🎨 Interface minimalista e funcional
- ⚡ Validação de campos no front-end

---

## 🚀 Como rodar

```bash
# Clone o repositório
git clone https://github.com/israelmarques1024-dotcom/projeto-login-capivara-tech.git

# Entre na pasta
cd projeto-login-capivara-tech

# Instale as dependências
npm install

# Inicie o servidor
npm start
```

Acesse em `http://localhost:3000`.

projeto-login-capivara-tech/
