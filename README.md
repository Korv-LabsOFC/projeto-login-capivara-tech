# Projeto Login Capivara Tech

Um sistema de login simples feito com Node.js + Express, HTML, CSS e JavaScript. Este foi o meu primeiro projeto envolvendo banco de dados!

Criado por **Israel Marques** (12 anos).

## Tecnologias

- Node.js + Express
- HTML5 + CSS3
- JavaScript
- SQLite3

## Como rodar

```bash
npm install
npm start
```
